# 0.9 主线核对表（含完整剧透）

玩家默认只会得到原始证据；本文件供回归测试和开发核对，不会展示在网站内。

## 主视角与避险

方位按HUD的北/东/南/西判断，旧文“右上”对应东北，并非当前摄像机的右前方。↑前进、↓倒退；←→转身；X/C侧移；R回头。互动必须面对物件。

镜宫调查多余的脸后，保持原朝向倒退或侧移三格，呼吸声消失后即可正常转身；提前回头180度（包括连续两次90度转向）会闪过异常面孔并受伤一次。只有主动调查这面镜子才启用规则，不会无预警处罚普通转身。

电轨：黄灯1.5秒预热→红电弧0.9秒→冷却；两排错相，中央两列绝缘。血手印：收拢1秒→抓握0.9秒→休眠，轮回间歇足够走开。计数器输错不会立即扣血：1.4秒内离开当前站位即可躲开手。拿玩偶代币前可取消；接受后有2.8秒起步宽限。读对白/暂停时危险时间不推进。

## 序章与第一章

1. 入口售票室抽屉取票与钥匙，返回开启检票闸，经过广场进入镜宫。
2. 档案室取镜片，读入藏簿：面具Ⅰ、飞鸟Ⅱ、眼睛Ⅲ、手掌Ⅳ。进入冲洗暗房读灯位标签，再到东侧校片间：缺口片西、箭头片东、水痕片南，试合遮光叶。回暗房再次调查红灯使其熄灭，从显影盘取底片。
3. 晾片说明提示背面观察会反转顺序。反面陈列室的镜背底片架依次输入手掌、眼睛、飞鸟、面具，确认排列。
4. 核验记录显示316人离园；计数器选316取得“看见”。从镜宫北门走维修回廊，绕过隔墙，去右上安全门。
5. 休息室恢复、存档。感谢岚救你可增加独立共同记忆。

## 第二章

1. 庭院乐谱：太阳在月亮前、星星不最后。检修间末页：星星紧接太阳。因此顺序是太阳、星星、月亮。
2. 从动力室进入配重检修间。配重锁放2格铜马与5格铁铃，使两端均为7，松锁取摇柄。
3. 配重检修间东侧进入液压间，可先操作活塞检修锁解除导轨危险。三缸初始8/0/0：主→副、副→缓冲、缓冲→主、副→缓冲、主→副、副→缓冲、缓冲→主，得到4/4/0，锁定压力。回动力室安装摇柄，按太阳、星星、月亮制动，取得“停下”。错误会复位，不扣票角；部分进度会保存。
4. 回庭院可取蓝色发带。庭院南侧偏西的欢乐街门已经开放，主线还剩三章。导览可核对出口方位。

## 第三章及巡游

1. 欢乐街柜台内侧取保险芯，调查控制板安装，再次调查开始操作。
2. 初始全部支路关闭。按甲、丙、丁，得到画面关、笑声关、赠奖关、退币开。选择试运行。联动开关可反复切换，所有状态均可恢复。
3. 柜台内侧东门通向作废票库。凭据甲单是未兑奖原始付款；乙单是补发、丙单已兑奖。在人工注销台选甲，取注销凭据，2.4秒内离开脚下掌印。奖品室取代币并逃出后，凭据与代币一起交还退币口取得“舍弃”。先拿代币或先修电路均可。
4. 碰碰车先去东南侧事故保护复位盒，再回西北侧断电开关。中央两列绝缘垫安全，轨道亮黄后才放电。也可以把握间歇直接通过。去巡游大道。
5. 巡游站位表：鼓手、笛手、提琴手。纸面具工坊三种乐器分别两短、一短、一长。组合得到短、短、短、长。
6. 三个乐器均调查后，关闭工坊南侧自动掌声磁鼓。回大道敲出四拍，触发纸人追逐，跑向东北剧场。重试会回到最后一声之前。

## 第四章

1. 前厅寄存处取雨伞胶片（孩子尚未受伤）；后台事故记录取熄灯胶片；母带放映机取录音和检修门胶片。
2. 更衣室化妆台取伤口胶片（发带包扎、灯仍亮）。带母带从更衣室进入录音间，近场低轨与远场高轨打开、广播轨关闭，转录原始现场。2.4秒内离开脚下掌印。试听会返回混音台；无论错误多少次，原带均保留。
3. 放映室按雨伞、伤口、熄灯、检修门重排并确认。支持撤回；未收齐不能接片。
4. 接片完成后影子离开银幕开始追逐，绕隔墙去右上安全门，回到后台。
5. 观众席拉开左右侧幕，调查银幕，选择看完原结局，取得“面对”。从舞台后的门进入湖畔。

## 第五章与终章

1. 湖畔与岚交谈。空白游客卡写下岚可取得名牌、增加共同记忆。
2. 沉船坞东侧进水闸房，先打开东侧泄水闸，再去西侧进水闸。每轮水势10秒，前4.5秒高水、后5.5秒低水；水尺低于白线时落下进水闸。错过窗口可继续等，没有伤害。回船坞操作排水泵，取铁匣钥匙。
3. 摩天轮卷扬井用钥匙开配电柜，再操作电机供电。
4. 站台控制盘从0开始，左齿轮＋4、右齿轮－3，按18格循环。目标17；一组解是左、左、右、右、右。放下停靠闸。
5. 再次调查控制盘，与姐姐告别，取得“告别”。没有取发带也可正常完成。
6. 地下控制区的五路滞留记录台逐项释放，进度可保存。全部释放后，在闭园开关决定闭园或继续营业；闭园后走出清晨的大门。

## 三种结局及支线

- 散场之后：闭园、岚的名牌、至少一次休息室或前厅的积极陪伴选择。名牌本身也贡献一段共同记忆。
- 记得一个名字：闭园，但条件未齐。
- 快乐，从不散场：留下继续营业。
- 摄影师、维修员、柜员、面具工、林晴、船坞和守夜人的记录组成七段可选人物记忆。发现至少五段，会改变清晨最后一张票的文字，不阻塞主线。

## 机制与验证

对白、菜单、背包暂停危险。对白计入游玩时间，菜单不计入。追逐禁止覆盖安全存档；失败恢复最近安全记录并补满票角。镜背、配重、电路、制动、铃声、胶片、齿轮均保留中间状态。求助不授予道具或印章。

自动通关使用真实移动、朝向、邻近调查与选项，不直接给主线测试授予印章。测试覆盖34处空间、触屏连续移动和可见表面点击、常速追逐、三结局、试错恢复、存档迁移与提示不会自动升级。另验证全部可达液压状态均可回到解，水尺画面确实随潮位变化。浏览器连接被环境限制，自动测试不是手机实机验证。
