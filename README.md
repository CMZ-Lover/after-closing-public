# 惊悚游乐场 / AFTER CLOSING

原创像素恐怖探索游戏。暮星游乐园，317人进入，316人离开。

公开试玩：https://cmz-lover.github.io/after-closing-public/ （以 GitHub Actions → deploy 成功为准）

公开源码仓库：https://github.com/CMZ-Lover/after-closing-public 。每次推送 main 都会运行测试、构建并部署 GitHub Pages；首次发布需在 Settings → Pages 选择 GitHub Actions。

## 0.8.1 触控稳定性修复

- 摇杆在全局松手、触摸结束/取消、失去捕获、切后台和页面离开时清零；双指操作分别追踪接触标识，重新按下可替换残留状态。不会用超时强制打断正常长按。
- 摇杆外沿连续加速；菜单可选低、标准、高三档视角灵敏度。
- 调查按最新视角命中物品；黑边不触发滑动。横屏也能看见“再靠近一点”等非阻塞提示。
- 静止及暂停时跳过无变化画面；物体表面共用当帧材质色缓存，减少重复计算。危险预警和惊吓动画仍更新。

仍需在真实手机上复测系统打断、双指松手和长按；自动检查不能保证所有浏览器的触摸事件行为一致。

## 0.8 指尖探夜

- 去除七个方向按钮和调查按钮。左下模拟摇杆连续移动，轻推慢走、推满快走，支持侧移和保持朝向倒退。
- 在画面上滑动自由转向、抬头和低头；两个指针分别控制摇杆和视角。松手、取消触摸、切换应用、暂停或弹出对白都会释放输入，滑动不会误触调查。
- 直接点击画面中看见的物品或门，靠近后才能操作。使用同一深度缓冲进行绘制和点击检测，隔墙、被遮挡、隐藏的物品不可点击。远处点击只提示靠近，不泄露记录。
- 桌椅、柜台、镜框、机关、玩偶、木马和摩天轮改成固定在场景里的立体几何物件；有侧面、顶面、材质明暗与地面接触阴影，不再始终正对镜头。
- 旧存档保留；新增连续位置和观察角度可以保存。镜宫使用调查时的真实视线作为基准，转向背后约150度开始显现异常人影。

维持五章、29区域、全部机关和三种结局。浏览器预览连接受当前环境限制，自动检查与离线校样不能代替手机实机试玩。

## 0.7 不要回头

29处区域全部切换为400×250的**人物主视角**：墙体遮挡、有限视野、真实比例的地面与正面设施。转身、前进和侧移逐段发现空间，不再整间房一屏可见。五章、三结局和已有v3存档保留；此轮没有扩大原有碰撞地图，而是重做视角、空间呈现与操作。

- 拆除电源、排水、拉开幕布、安装摇柄、制动等明显变化直接更新画面和音效，不再要求点“继续”。记录、人物对话与有后果的选择仍保留。
- 镜宫的“不要回头”成为真实机制：调查多余的脸后，岚先警告；倒退或侧移离开三步可安全脱身，转180度会先出现异常人影，220毫秒后损失一个票角。一次遭遇只处罚一次，警告状态可存档。
- 电轨有1.5秒黄灯预警；血手印先收拢1秒再抓脚，休眠期仍看得见。错误核验有1.4秒伸手前摇，离开脚下位置便可闪避。
- 玩偶拿币前给出危险征兆和取消选择；追逐有起步宽限，脚步方位以文字同时提示，静音也能规避。追逐速度为主视角转身时间重新调整。
- 每次受伤触发一次650毫秒全屏暗红脉冲、短震动及票角反馈。“动态少”关闭红闪、抖动和人影横移，保留静态红边。

此版本源码及构建产物由GitHub Actions检查；在线链接是否更新以实际部署成功为准。浏览器预览访问被当前环境阻止，不能把离线校样与单元测试当成实机试玩。

## 0.6 内容基础（保留）

从入口到闭园的五章主线，29处可探索区域、五枚印章、四段敌人追逐、通电陷阱、跨房间物品链、调查手记、岚的陪伴选择与三种结局。声音为本项目的Web Audio合成，不依赖外部素材服务。

本轮新增冲洗暗房、配重检修间、柜台内侧、纸面具工坊、更衣室、放映室、沉船坞、卷扬井。每处参与线索、道具或机关链。

主要改动：底片方向与档案顺序推理、配重与分散曲谱、联动电路、余音组合、四段胶片重排、摩天轮循环齿轮。机关支持撤回、试错、退出与读档。失败反馈不直接告诉玩家答案。求助分为观察、关联、明确解法，最后一级必须主动选择。

导览展示五章进度、当前房间的出口方位与开放状态；第二章结束不代表游戏结束。当前标题右上角显示“0.8 · 指尖探夜”。

这是一版可走完故事的独立试玩，后续仍需实际玩家反馈调整叙事、追逐难度和手机布局，并非已完成全部质量打磨的商业版本。

## 操作

- 手机：左下摇杆移动，推满快走；下拉倒退、左右侧移。在画面上左右滑动转身、上下滑动抬头低头；靠近后点击物品或门。支持双指同时移动和观察。
- ↑ / W：前进；↓ / S：倒退但不转身。← → / A D：连续左右转向。
- X / C：左右侧移；R：回头180度。Shift：快走。鼠标拖动画面转向、点击物品调查。
- Z / E / 空格：调查准星所指的物品或继续对白。
- B：背包；J：手记；M：导览；Q：可选求助；Esc：暂停。对白中可用方向键选择按钮、Enter确认。
- 绿色灯旁的留言簿恢复票角并保存。追逐中可以暂停，不能存档；失败回到最近安全记录。
- 设置可以关闭声音、减少画面动态，或将追逐速度调为舒缓。

存档只保存在当前浏览器。0.6使用`after-closing.save.v3`，可以自动接续0.5的v2存档，保留已取得的印章并兼容新增关卡门锁。旧v2记录不会被覆盖或删除。想完整体验重做后的前两章可选“新的旅程”，但不是强制要求。0.3的原型存档不兼容。

## 本地开发

```sh
npm ci
npm run dev
npm test
npm run build
```

`dist/`是静态网站产物；没有服务器数据库或付费API。Phaser 3负责画面与输入呈现，`engine.ts`中的主线状态、追逐和伤害逻辑可以独立测试。

`npm run art:proof -- /绝对路径`输出与游戏使用同一像素绘制数据的场景渲染图。它们是离线美术校样，不冒充浏览器截图。
